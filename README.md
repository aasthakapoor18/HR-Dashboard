# HR-Dashboard
This project is an interactive HR Analytics Dashboard built using Power BI. The dashboard helps analyze employee attrition, workforce demographics, salary distribution, job satisfaction, and department-wise trends.
Tools Used: Power BI
            Power Query
            DAX
            Excel Dataset
Key Metrics:  Total Employees
              Active Employees
              Attrition Count
              Attrition Rate
              Average Age
              Average Experience
Dashboard Insights:   Department-wise attrition analysis
                      Salary slab-wise attrition trends
                      Job role and job satisfaction analysis
                      Employee distribution by age group
                      Gender-wise attrition comparison
                      Experience-based attrition patterns
